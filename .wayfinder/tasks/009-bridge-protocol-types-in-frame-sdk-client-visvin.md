## Task

Define the contract every other Tools task builds against, and the browser-side SDK + UI kit that runs INSIDE the sandboxed iframe (imported by Tool bundles as `@visvine/tool-kit`).

**apps/web/lib/tools/protocol.ts** (pure types + tiny helpers, no React): `PROTOCOL_VERSION = 1`; host→frame messages: `{ type: 'visvine:init'; version; theme: Record<string,string>; subject: ToolSubject|null; install: { slug: string; title: string; key: string } | { preview: true; name: string }; degraded: { missing: { connectors: string[]; types: string[]; agents: string[] } } | null; viewer: { id: string; name: string; isAdmin: boolean } }`, `{ type: 'visvine:result'; id: string; ok: true; value: unknown } | { …; ok: false; error: BridgeError }`, `{ type: 'visvine:theme'; theme }`, `{ type: 'visvine:subject'; subject }`; frame→host: `{ type: 'visvine:ready'; version }`, `{ type: 'visvine:call'; id; method: BridgeMethod; params: unknown }`, `{ type: 'visvine:resize'; height: number }`, `{ type: 'visvine:error'; message: string; stack?: string }`, `{ type: 'visvine:navigate'; path: string }` (host validates: only in-app paths). `ToolSubject = { kind: 'note'; path: string; type: string|null; title: string|null } | { kind: 'node'; nodeId: string; type: string; notePath: string|null }`. `BridgeMethod` union with param/result types: `context.list {glob?} → {path,title,type,updatedAt}[]`, `context.read {path} → {path, content, frontmatter}`, `context.search {query,k?} → hits[]`, `context.write {path, content} → {path}`, `context.append {path, text} → {path}`, `connectors.call {name, code} → unknown`, `agents.run {name} → {runId}`, `data.call {fn, args} → unknown`, `state.get {key} → unknown|null`, `state.set {key, value} → null`, `subject.get {} → ToolSubject|null`. `BridgeError = { code: 'perimeter'|'forbidden'|'not_found'|'rate_limited'|'too_large'|'timeout'|'invalid'|'degraded'|'internal'; message: string }`. REST envelope for the host: `BridgeRequest = { target: { kind:'install'; installId } | { kind:'preview'; spaceId; name }; method; params }`, `BridgeResponse = { ok: true; value } | { ok: false; error: BridgeError }`. Type guards `isHostMessage`, `isFrameMessage`, and `BRIDGE_LIMITS = { maxRows: 200, maxReadBytes: 256_000, maxWriteBytes: 128_000, maxParamsBytes: 64_000, callsPerMinute: 120, dataCallTimeoutMs: 20_000 }`.

**apps/web/features/tools/kit/** — a self-contained package folder compiled LATER by esbuild into a browser ESM bundle (keep imports to `react` and `react/jsx-runtime` only; no `@/` imports except type-only from '@/lib/tools/protocol'). Files: `client.ts` (postMessage bridge client: `createBridgeClient(win: Window, parentOrigin: string)` with request/response correlation by id, timeouts, `call(method, params)`, `onInit/onTheme/onSubject` subscriptions, `ready()`, `reportError`, `resize`; talks ONLY to `window.parent` and checks `event.origin === parentOrigin`), `hooks.tsx` (`VisvineProvider`, `useVisvine()` → `{ context, connectors, agents, data, state, subject, viewer, install, degraded, navigate }`, `useSubject()`, `useTheme()`, `useQuery(fn, deps)` small async helper), `components/` (Button, Card, Stack, Field/Input/Select/Textarea, Chip, Tabs, Table, EmptyState, Spinner, Banner, PageHeader — styled ONLY with CSS custom properties `--color-brand-green`, `--vv-*` tokens applied on `:root` by the runtime from the init theme map; ship `kit.css` as a string export `KIT_CSS` injected once by the runtime), `index.ts` re-exporting everything (this is the `@visvine/tool-kit` surface). Also `runtime.ts`: `bootTool(loadModule: () => Promise<{ default: React.ComponentType }>)` — used by the frame document: creates the client, awaits `visvine:init`, applies theme vars + KIT_CSS, mounts `<VisvineProvider><Tool/></VisvineProvider>` into `#root` with react-dom/client, wires ResizeObserver → `visvine:resize`, error boundary → `visvine:error`.

**apps/web/lib/tools/sdkDocs.ts**: `TOOL_KIT_DTS: string` (a hand-maintained `.d.ts` for `@visvine/tool-kit` matching the exports above) and `TOOL_AUTHOR_GUIDE: string` (markdown: file layout ui.tsx/data.js/index.md, frontmatter perimeter/surfaces, `export default function Tool()`, `handlers.<name> = async (args, visvine) => …` for data.js, limits, do/don't). Served later by MCP `get_tool_sdk` and docs.

## Outcome
